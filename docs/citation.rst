Citation
========

If you use peptacular in research, cite the archived software release. The DOI
`10.5281/zenodo.15054278 <https://doi.org/10.5281/zenodo.15054278>`_ covers all
versions. Each release also receives a version-specific DOI from Zenodo. A JOSS
paper is in preparation.

The repository's
`CITATION.cff <https://github.com/tacular-omics/peptacular/blob/main/CITATION.cff>`_
file holds machine-readable citation metadata. GitHub's **Cite this repository**
menu renders it as APA or BibTeX.
