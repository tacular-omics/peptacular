Changelog
=========

Release notes for every version, including migration notes for breaking
changes, are kept in
`CHANGELOG.md <https://github.com/tacular-omics/peptacular/blob/main/CHANGELOG.md>`_
on GitHub. Releases are also listed on the
`GitHub releases page <https://github.com/tacular-omics/peptacular/releases>`_
and on `PyPI <https://pypi.org/project/peptacular/>`_.
